# 音乐排行榜

个人技术整合练习项目，作为期末大作业的原型。

## 项目简介

一个音乐排行榜单页应用，整合了**页面、样式、交互、数据可视化**四个模块，主题围绕华语热门歌曲榜单展开。

## 运行方式

直接用浏览器打开 `index.html` 即可，无需服务器、无需联网（数据内置在 `data.js` 中）。

```
双击 index.html
```

## 文件结构

```
.
├── index.html   # 页面结构：导航、榜单、收藏、数据看板
├── style.css    # 样式：卡片、排名徽章、三档响应式
├── data.js      # 数据：10首歌曲样本 + 收藏持久化
└── main.js      # 交互与可视化：渲染、搜索、排序、播放、收藏、柱状图
```

## 功能模块

| 模块 | 说明 |
|:---|:---|
| 页面 | 顶部导航 + 搜索框，三个标签页（热歌榜 / 我的收藏 / 数据看板） |
| 样式 | 渐变导航栏、金银铜排名徽章、卡片悬浮动效、三档响应式布局 |
| 交互 | 搜索过滤、排序切换、播放状态栏、收藏/取消收藏（localStorage） |
| 可视化 | Canvas 绘制播放量柱状图，含 Y 轴刻度、X 轴歌曲名、渐变柱体 |

## 模块间数据衔接

- 热歌榜的「收藏」操作 → 数据写入 `localStorage` → 收藏页读取并展示
- 搜索关键词作用于热歌榜列表，无结果显示空提示
- 数据看板读取同一份 `songs` 数据，与榜单保持一致
